# Developer Profile Website

Simple single-page developer profile scaffold. Open `index.html` in a browser to view.

How to use

- Edit the content in `index.html` to add your name, bio, projects, and links.
- Customize styles in `styles.css`.
- `script.js` provides a theme toggle and a placeholder contact form handler.

Included files

- `resume.txt`: plain-text copy of the resume content you provided. Convert to PDF locally or ask me to generate a PDF for you.

Preview

Double-click `index.html` or serve the folder with a static server, e.g.:

```bash
# Python 3
python -m http.server 8000

# Node (install serve)
npx serve .
```
